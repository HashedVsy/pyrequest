# PyRequest

A small Python HTTP client for simple GET and POST requests.

## Dependencies

To run PyRequest, you will need [Requests](https://pypi.org/project/requests/).

If you would like to run the example server, you will also need [Flask](https://pypi.org/project/Flask/).

> **Note:** Flask's built-in server is intended for development.
> Production servers should use a production WSGI server.

## Quick Start

To use PyRequest, first install the [dependencies](#dependencies).

Then run:

```bash
python pyrequest.py
```
